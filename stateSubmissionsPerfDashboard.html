State Submissions Performance Dashboard

The State Submission Performance Dashboard is an interactive data analytics project designed to track and visualize the timeliness of data submissions from various U.S. states. Using a mock dataset simulating six months of submission data, the dashboard highlights key performance indicators (KPIs) such as on-time submission rates, late and missed submissions, and monthly performance trends.

The project demonstrates my ability to:

  • Clean and prepare datasets
  • Perform SQL-based analysis
  • Build interactive and insightful Power BI dashboards
  • Present data in a way that supports decision-making

It was developed to mirror real-world reporting scenarios, making it relevant for compliance tracking, operations performance monitoring, and public sector analytics.

Features

  • KPI Card - Displays overall on-time submission percentage.
  • Bar Chart - Shows on-time submission rate by state for easy comparison.
  • Line Chart - Tracks trends in on-time performance month-over-month.
  • Pie Chart - Illustrates the proportion of on-time, late, and missed submissions.
  • Interactive Slicer - Allows filtering dashboard views by state.
  • Detailed Table View - Lists all late and missed submissions with expected and actual dates.
  • Custom Layout - Designed for clarity, with interactive elements grouped logically for intuitive navigation.

Tech Stack

This project was built using:

  • Python Dataset generation and preprocessing
  • SQL Data querying and transformation
  • Power BI Data modeling, visualization, and dashboard design
  • Power Query Editor Data cleaning and formatting
  • Pandas (in Python) to simulate and export mock dataset
